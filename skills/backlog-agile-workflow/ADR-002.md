# ADR-002 — Roadmap y ADR mantienen autoridad; backlog es proyección operativa

**Estado:** aceptado para la skill (2026-10-28). Esta decisión no modifica repositorios consumidores.

## Contexto

Un roadmap puede mezclar hitos pendientes, cortes históricos, investigación, releases y recibos; ADR y SPEC fijan reglas y contratos. Crear una tarea por encabezado duplica trabajo e invalida trazabilidad, sobre todo cuando ramas y worktrees difieren.

## Decisión

1. No sincronizar Markdown de forma automática. El agente inspecciona fuentes canónicas y construye un paquete `spec-packet` **curado y temporal**; cada elemento conserva `sourceRef` estable, sin alterar documentos.
2. Milestones representan entregas; tareas representan capacidad/cambio verificable; ADR/SPEC/gates/recibos son referencias salvo acción explícita. Estados documentales y `Done` en Backlog.md no certifican un producto.
3. Proyector Python puro `spec_projection.py`: valida paquete, dependencias acíclicas y JSON del corpus visible; propone creaciones, revisiones, preservación histórica o inspección. Nunca invoca CLI, Git ni aplicaciones.
4. Reconciliación idempotente **por referencia exacta** de origen; ante corpus filtrado, ambiguo, formato desconocido, título coincidente, tarea archivada o dependencia sin ID CLI, falla cerrado o propone revisión. No destruye progreso ni reescribe documentos.
5. La priorización `P0..P3` es una **recomendación ordinal** basada en factores documentados, no corresponde directamente a los valores configurados de Backlog.md. Requiere deliberación y lectura de configuración real antes de aplicarse.
6. La ejecución por CLI oficial y los cierres se realizan con autorización, configuración Git inspeccionada y evidencia externa de tests, merge/release y certificación si el proyecto lo exige.

## No objetivos

No implementar un importador que escriba tareas, otro estado, un motor de scheduling, un parser universal de Markdown, un proceso permanente ni un reemplazo de Backlog.md. No gestionar los documentos originales mediante scripts de esta skill.
