# Lente: accesibilidad y seguridad de menores

- WCAG 2.2 como referencia: semántica de botones, etiqueta visible, foco perceptible, orden de tabulación, contraste, targets táctiles razonables, zoom y orientación.
- `prefers-reduced-motion`: desactivar motion no esencial, ofrecer alternativa estática y evitar contenido con destellos o loop distractor.
- Mapas/drag: alternativa teclado y texto/botones con el mismo resultado; SVG con etiquetas/puntos de interacción equivalentes; no usar color como único canal.
- Sonido: nunca obligatorio ni autoplay para resolver, volumen/mute visible; mensajes de error no invasivos.
- Lectura: instrucciones progresivas y ayudas concretas, modo simple, tipografía legible; no simplificar falsamente hechos.
- Menores: offline/local por defecto, sin cookies de tracking, anuncios, login, datos personales ni rankings públicos. Revisar requisitos jurídicos si se aloja como servicio y se almacenan datos de niños.
- Ofrecer modo tranquilo sin cronómetro/XP a la vista ni castigos por descanso. No usar mecanismos de recompensa tipo juego de azar.

Comprobar interacción real con teclado y móvil; no dar por accesible solo por incluir `aria-label`.
