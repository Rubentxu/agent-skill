# Patrón: laboratorio simulable

Acción: formular una predicción, cambiar parámetro, observar el efecto, explicar contraste. Escena de SVG/Canvas con sliders y lectura textual equivalente. Motor determinista o modelo físico explícito; si se simplifica, avisarlo.

Ejemplo: mezcla de colores o fracciones; controlar cantidad con botones/slider, mostrar el objeto transformándose y pedir transferir principio a nueva situación. Error: predicción desmentida → explicación causal, reintento, variante. No usar gráficos espectaculares como sustituto de explicación científica.
