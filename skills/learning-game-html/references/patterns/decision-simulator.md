# Patrón: simulador de decisiones

Acción: elegir entre opciones con trade-offs, justificar criterio y observar consecuencias modeladas. Útil para economía, programación, seguridad o habilidades adultas. Evitar premiar decisiones «rápidas» cuando importa razonar.

Representar consecuencias con una máquina de estados pequeña y reproducible, no números mágicos; explicar límites del modelo. Evaluar transferencia a un caso nuevo, con datos o circunstancias cambiadas.
