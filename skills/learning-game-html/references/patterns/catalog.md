# Catálogo de patrones jugables (no plantilla universal)

Elegir por **operación cognitiva y evidencia**, no por su aspecto. Abrir solo la receta necesaria:

| Conocimiento | Patrón | Receta |
|---|---|---|
| Espacial y asociaciones | Atlas vivo / exploración | [interactive-map](interactive-map.md) |
| Variables y causalidad | Laboratorio / simulación | [virtual-lab](virtual-lab.md) |
| Recuperar recuerdos | Palacio de memoria / tarjetas | [memory-palace](memory-palace.md) |
| Eventos y contexto | Detective / cronología | [detective-timeline](detective-timeline.md) |
| Resolución por pasos | Escape room y puzzles | [escape-room](escape-room.md) |
| Juicio con consecuencias | Decisiones / simulación | [decision-simulator](decision-simulator.md) |

Los patrones ofrecen *recetas*, no librerías que deban instalarse. Una escena puede combinar dos patrones si la evidencia lo justifica. Reutilizar el mismo contenido no significa que las respuestas siempre se puedan evaluar igual.
