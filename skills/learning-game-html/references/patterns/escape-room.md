# Patrón: escape room educativo

Acción: encadenar 3–4 desafíos de una materia; cada candado exige **demostrar** una idea o técnica, no acertar al azar. Pistas accesibles y reintento sin perder lo aprendido. El decorado avanza por retos; puerta o bóveda se abre con transición breve y feedback contextual.

No esconder información esencial en hover, audio o drag exclusivo. La exploración es opcional; el aprendizaje debe poder realizarse desde un modo simplificado.
