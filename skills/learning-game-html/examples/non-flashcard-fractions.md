# Ejemplo de vertical no-Anki: Fracciones espaciales

**Meta**: manipular dos fracciones y explicar por qué son equivalentes. Público principiante, estética estación espacial; evitar infantilizar por edades.

**Primera escena**: visor circular SVG donde se activan porciones. «Divide»/«Colorea» tiene controles de teclado y botones alternativos. Se propone equivalencia; alumno crea 1/2 y 2/4 sin ver la respuesta.

**Bucle**: experimenta → predice → construye → compara → explicación concreta si falla → prueba equivalente nueva → recompensa de reconstruir un módulo espacial una sola vez por concepto demostrado.

**UAT**: construir 2/4; error en partes desiguales muestra explicación correcta; sin mouse se completa; recarga mantiene progreso; con movimiento reducido sigue funcional; nueva variante 3/6 evalúa dominio.
