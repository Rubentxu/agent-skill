# UAT de una experiencia jugable (efímero)

| ID | Preparación | Acción y observación obligatoria |
|---|---|---|
| U1 | Primera carga | Se entiende el objetivo y empieza actividad real |
| U2 | Desafío activo | Acción correcta produce feedback específico y siguiente reto |
| U3 | Desafío activo | Error produce explicación/pista y opción real de recuperación |
| U4 | Progreso | Recarga conserva progreso sin duplicar recompensas |
| U5 | Sesión completada | Elegir práctica libre produce actividad; reiniciar no borra historial |
| U6 | Móvil/teclado | Interacción completa sin arrastre exclusivo, foco visible |
| U7 | Preferencia reducida | Escena jugable sin depender de movimiento continuo |
| U8 | Sin red (si prometido) | Se abre, carga datos y permite actividad sin solicitudes externas |

Observar/guardar únicamente evidencia mínima (capturas para layout, eventos para funcionalidad, fixture de storage para migraciones). Si la herramienta no existe, `NOT_RUN`. El test UAT puede eliminarse tras decidir `promote|replace|retire` de conformidad con las garantías.
