# Wow Gate — evaluación visual operativa

**No es un número mágico de diseño ni un sustituto de revisión humana.** Puntúa `0=ausente/roto`, `1=aceptable`, `2=excelente`; cada criterio requiere observación real.

| Dimensión | Qué observar |
|---|---|
| 1. Identidad visual | Metáfora y lenguaje gráfico coherentes, no dashboard genérico |
| 2. Composición | Jerarquía, alineación, legibilidad, uso del espacio, densidad |
| 3. Escena protagonista | Interacción real y causal, no imagen simulando juego |
| 4. Motion semántico | Transiciones que orientan/revelan; sin saturación y con reducción |
| 5. Feedback y emoción | Error explicado, pista accionable, recompensa adecuada |
| 6. Estados | Inicio, juego, vacío, complete, fallo, repetir sin trampas |
| 7. Responsive | 390/768/1440 o dispositivos pertinentes; sin overflow ni targets diminutos |
| 8. Accesibilidad | Teclado/foco/contraste/texto y alternativa a gestos/audio |
| 9. Robustez | Recarga/persistencia/restauración y controles en extremos |
| 10. Ritmo | Primera interacción inmediata, poca latencia, sin bucles distractores |

**Cierre**: ninguna dimensión crítica (3, 5, 7, 8, 9) puede valer 0. `VISUALLY_REVIEWED` es independiente de `BROWSER_FUNCTIONAL` y de `LEARNING_EFFECTIVE`; no atribuir ningún sello por cumplir un total numérico. Que sea **bonito** no autoriza a llamarlo **pedagógicamente eficaz**.

Escenas adaptables: Atlas vivo con rutas, laboratorio en SVG, tablero de escape room, museo exploratorio, timeline, simulador de dilemas. Comparar con la intención del usuario, no copiar marcas ajenas.
