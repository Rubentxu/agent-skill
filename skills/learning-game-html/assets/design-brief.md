# Game Build Brief (mínimo)

- Audiencia y nivel observado; idioma; opciones de accesibilidad.
- Objetivo observable, contenido/ID, fuentes y errores frecuentes.
- Mecánica: qué hace la persona y cómo se evalúa su respuesta.
- Idea visual: metáfora, escena protagonista, animaciones significativas, estados/feedback.
- Primera vertical: inicio → desafío → éxito/fallo → ayuda → siguiente.
- Persistencia y compatibilidad; distribución offline o stack existente.
- Recompensas no manipuladoras, idempotentes y separadas de mastery.
- Criterios de aceptación en navegador + fallos prioritarios.

Si falta `playful-learning-design`, el agente produce un brief provisional suficiente, sin inventar validaciones educativas.
