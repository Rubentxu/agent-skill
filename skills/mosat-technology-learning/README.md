# mosat-technology-learning

Skill autocontenida para investigar y aprender tecnologías digitales mediante **MOSAT (Método Ontológico-Sistémico para el Aprendizaje de Tecnologías Digitales)**, adaptado a trabajo agent-first con trazabilidad de evidencia, análisis de gaps y condiciones explícitas de cierre.

## Cuándo usarla

Úsala para comprender una tecnología antes de adoptarla, integrarla, compararla, enseñarla o tomar una decisión arquitectónica. No está pensada para consultas rápidas, tutoriales paso a paso ni troubleshooting puntual cuando ya existe un modelo suficiente del sistema.

## Qué produce

- alcance y objetivo de aprendizaje;
- bibliografía organizada por perspectiva;
- fichas MOSAT con preguntas, respuestas, evidencia y vacíos;
- modelos conceptuales, estructurales, funcionales y dinámicos/contextuales según necesidad;
- registro de contradicciones, supuestos e incógnitas;
- criterio de convergencia y entregable orientado a la decisión.

## Base metodológica

La formulación base procede de Jonás A. Montilva C. y William Montilva, *Un método ontológico-sistémico para el aprendizaje conceptual de tecnologías digitales*, Revista Ciencia e Ingeniería, Vol. 39, No. 3, 2018, y de la presentación pública del autor sobre apropiación tecnológica. Esta skill no reproduce sus tablas de forma literal: conserva los principios y añade mecanismos agent-first identificados explícitamente como extensiones.
