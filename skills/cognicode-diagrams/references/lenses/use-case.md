# Lente futura: `use-case` — **PLANNED, NO ACTIVA**

No usar esta ficha como prueba de implementación. Antes de habilitar: concretar ontología (actor, objetivo, precondición, escenario principal, alternativas, poscondición), fuentes de requisitos y tests de aceptación. Una función pública o endpoint no prueba un caso de uso de negocio.

Compatibilidad futura: Mermaid flowchart puede representar un mapa de casos de uso de forma **adaptada**; Structurizr puede representar interacciones de actores y sistemas, pero NO equivale automáticamente a un UML Use Case. Separar descripción del caso de uso del artefacto visual. Probar lectura de fuentes, validación y pérdidas.
