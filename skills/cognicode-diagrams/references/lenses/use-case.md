# Lente futura: use-case — PLANNED

Un actor, objetivo o escenario de negocio **no se demuestra con el nombre de una función ni con README/ADR/roadmap/test**. Activar solo si CogniCode CLI/MCP permite vincular rutas **implementadas** y fragmentos de código al comportamiento afirmado. Preguntar por entradas, autorización, flujo y salidas; sin prueba declarar `UNKNOWN`, no buscar requisitos con herramientas alternativas.

Mermaid flowchart puede representar de forma adaptada un mapa de casos de uso, no UML Use Case nativo; Structurizr no sustituye esa semántica. El agente no puede inventar actores, políticas de negocio o desenlaces.
