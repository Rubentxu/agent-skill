# Lente: conocimiento y confusiones previsibles

- Clasifica unidades: `fact|concept|procedure|causal-model|decision|spatial|timeline`. Establece ID duradero, relación y prerequisito.
- Consulta fuentes primarias adecuadas al contenido y fecha; una fuente sin contrastar = `unverified`. No rellenes lagunas con invenciones.
- Anticipa dos **errores concretos** por concepto: confusión visual, paso omitido, respuesta popular incorrecta, conocimiento previo erróneo.
- Para geografía: territorios, capitales múltiples, fronteras y cambios históricos requieren aclaración y fecha. El mapa es ayuda, no prueba de dominio si la solución queda resaltada.
- Para ciencias: distingue modelo didáctico simplificado de fenómeno real; anota alcance. Para historia: hecho, interpretación y controversia separados.
- Salida mínima: unidades de conocimiento + errores + fuentes/fecha/confianza + contraejemplo. No usar imágenes vistosas para esconder errores factuales.
