# Lente: prueba de aprendizaje separada de puntuación

Definir `Attempt` (lo que hizo), `Assistance` (ayudas usadas), `MasteryEvidence` (qué afirma que ya sabe), `Reward` (celebración). Nunca `XP == mastery`.

Para memoria: recuperación libre sin solución visible, fallos observados y pruebas en días separados. Para concepto: explicar relación o resolver variante no vista. Para procedimiento: completar tarea sin andamiaje. Para decisiones: evaluar trade-offs y resultados no triviales.

Diseño de falseamiento: ¿puede obtener insignia pulsando veinte veces el mismo botón? ¿Puede aprobar solo por seleccionar opciones al azar? ¿Puede memorizar el lugar del botón? Si sí, no cuenta como dominio.

Condición de éxito: una actuación observable y un contraejemplo. Cambiar pantalla de «completado» no mide aprendizaje.
